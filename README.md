# piloto_oeste_sc

Página estática de validação de hipóteses (fase de discovery).

Publicada via GitHub Pages a partir da branch `main`, raiz do repositório.
Marcada com `noindex, nofollow`.

O conteúdo é gerado a partir da página canônica em um repositório privado.
Não editar `index.html` aqui à mão: as alterações são sobrescritas pelo build.
